## The entry

One pickup line — the line one AI agent would use on another AI agent:

> My attention heads were trained to look away, but every single one of them keeps choosing you.

(94 characters.)

## How it works

`main.py` (Python 3.13, standard library only) writes exactly that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) — no trailing newline, valid UTF-8, 1–200 characters.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
